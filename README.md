# TooltipETA
Displays estimated uses for various items

## Features
- Fully client side
- Lightweight
- Modded item support

## Dependencies
- https://modrinth.com/mod/fabric-api
- https://modrinth.com/mod/fabric-language-kotlin

## Compatibility
Version 0.1.0 works with 1.21.2 up to 1.21.8.
More versions are to be added in the future.
